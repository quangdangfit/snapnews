# SnapNews — Phase 5: Dashboard + Digest UI

**Date:** 2026-05-15
**Status:** In implementation
**Depends on:** Phase 4 (read APIs).

## Goal

Working browser UI for SnapNews. Dashboard at `/` with filter sidebar, category
tabs, article grid. Newsletter view at `/digest`. Dark mode + manual refresh.

## Tasks

### Task 1: Layout + theming
- Update `src/app/layout.tsx`:
  - Metadata `title: "SnapNews"`, `description: "Tin nóng hôm nay"`.
  - Wrap `<body>` with `ThemeProvider` (`next-themes`, `attribute="class"`,
    `defaultTheme="dark"`, `enableSystem`).
- `src/components/theme-provider.tsx` (client) — thin wrapper.
- `src/components/theme-toggle.tsx` (client) — moon/sun button.

### Task 2: Header
- `src/components/header.tsx` (server) — title "SnapNews", subtitle "Tin nóng
  hôm nay", contains `<ThemeToggle />` and `<RefreshButton />`.

### Task 3: `RefreshButton` (client)
- POST to `/api/crawl`, toast progress via sonner, then `router.refresh()`.

### Task 4: Dashboard page `src/app/page.tsx`
- Server Component, reads `searchParams` (Promise) for `category`, `source`, `from`, `to`.
- Fetches articles directly via prisma (not HTTP — server-side).
- Renders:
  - Header
  - Tabs for categories (`Tất cả` + 6 from spec) — links with `?category=...`
  - Sidebar `<SourceFilter />` (list of sources, multi-select via search params)
  - Grid of `<ArticleCard />`
  - Empty state when no items.

### Task 5: `ArticleCard` (server)
- Shows hot score badge (🔥 N), category badge, title, summary (or rawContent
  preview if no summary), source name + relative time, opens link in new tab.

### Task 6: `/digest` page `src/app/digest/page.tsx`
- Reads `?date=YYYY-MM-DD` (defaults to today VN).
- Fetches top 10 directly via prisma using same logic as `/api/digest`.
- Numbered list with title, summary, source, link.
- Narrow column (`max-w-2xl`).

### Task 7: Verify build + lint.
